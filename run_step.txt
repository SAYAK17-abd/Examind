================================================================================
EXAMIND — COMPLETE STEP-BY-STEP RUN & PLATFORM GUIDE
================================================================================

This document contains everything you need to run, test, and manage the full
EXAMIND platform (Spring Boot Backend + FastAPI AI Service + React Frontend)
on Windows.

--------------------------------------------------------------------------------
1. PREREQUISITES
--------------------------------------------------------------------------------
- OS: Windows 10/11
- Java: JDK 21 LTS installed
- Python: Python 3.11 installed with pip
- Node.js: Node 20+ installed
- Terminal: Windows PowerShell or Command Prompt

--------------------------------------------------------------------------------
2. ONE-CLICK LAUNCHER (RECOMMENDED)
--------------------------------------------------------------------------------
To start all 3 services simultaneously in separate PowerShell windows:

Step 1: Open PowerShell in the project directory:
        cd "d:\CODES\project.all\own\AI_projects\EXAMIND"

Step 2: Run the full-stack launcher:
        .\run_all.ps1
        (or double-click run_all.bat)

This automatically launches:
  - Python FastAPI AI Service: http://localhost:8000
  - Spring Boot Backend:       http://localhost:8080
  - React/TypeScript Frontend: http://localhost:5173

--------------------------------------------------------------------------------
3. RUNNING SERVICES INDIVIDUALLY (LOCAL DEV)
--------------------------------------------------------------------------------

(A) BACKEND (Spring Boot with In-Memory H2 Database):
    cd "d:\CODES\project.all\own\AI_projects\EXAMIND"
    .\mvnw.cmd spring-boot:run
    Live on: http://localhost:8080

(B) AI & OCR SERVICE (FastAPI):
    cd "d:\CODES\project.all\own\AI_projects\EXAMIND\ai-service"
    python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
    Live on: http://localhost:8000
    Interactive Docs: http://localhost:8000/docs

(C) FRONTEND (React + Vite):
    cd "d:\CODES\project.all\own\AI_projects\EXAMIND\frontend"
    .\pnpm.cmd dev
    Live on: http://localhost:5173

--------------------------------------------------------------------------------
4. ACCESSING WEB INTERFACES
--------------------------------------------------------------------------------

(A) FRONTEND WEB APP:
    URL: http://localhost:5173
    - Student Examination & Submission Portal
    - Teacher Exam Authoring, Question Palette, Rubrics & Override Portal
    - Admin User Management & Audit Dashboard

(B) SWAGGER UI (API Documentation & Testing):
    URL: http://localhost:8080/swagger-ui.html
    - Interactive testing for all Student, Teacher, Admin, AI, and File APIs.
    - OpenAPI Raw JSON: http://localhost:8080/api-docs

(C) H2 DATABASE WEB CONSOLE:
    URL: http://localhost:8080/h2-console
    Setting Name: Generic H2 (Embedded)
    Driver Class: org.h2.Driver
    JDBC URL:     jdbc:h2:mem:examind_dev
    User Name:    sa
    Password:     (leave completely empty)

--------------------------------------------------------------------------------
5. DEFAULT ADMIN CREDENTIALS (AUTO-SEEDED ON STARTUP)
--------------------------------------------------------------------------------
The application automatically creates the initial platform administrator:
- Email:    admin@examind.ai
- Password: Admin@Examind2026!
- Role:     ROLE_ADMIN

HOW TO AUTHORIZE IN SWAGGER UI:
1. In Swagger UI, go to "Authentication" -> "POST /api/auth/login"
2. Execute login with admin credentials and copy the "accessToken".
3. Click the green "Authorize" button at top-right, enter "Bearer <token>", and save.

--------------------------------------------------------------------------------
6. RUNNING WITH DOCKER COMPOSE (PRODUCTION CONTAINER STACK)
--------------------------------------------------------------------------------
Step 1: Copy environment configuration:
        copy .env.example .env
        (Edit .env and set secure POSTGRES_PASSWORD and JWT_SECRET)

Step 2: Start all containers in the background:
        docker compose up --build -d

Step 3: Check container status:
        docker compose ps

Step 4: To stop the containers:
        docker compose down

--------------------------------------------------------------------------------
7. RUNNING AUTOMATED TEST SUITES
--------------------------------------------------------------------------------

(A) BACKEND TESTS (19/19 Passing):
    .\mvnw.cmd test

(B) AI & OCR SERVICE TESTS (41/41 Passing):
    python -m pytest ai-service/tests/ -v

(C) FRONTEND TESTS (13/13 Passing):
    cd frontend; .\pnpm.cmd test

--------------------------------------------------------------------------------
8. COMMON TROUBLESHOOTING
--------------------------------------------------------------------------------

Q1: "Port 8080 was already in use"
A1: An older instance of the backend is still running. In PowerShell, run:
    Get-Process -Id (Get-NetTCPConnection -LocalPort 8080).OwningProcess | Stop-Process -Force

Q2: "Port 5173 was already in use"
A2: In PowerShell, run:
    Get-Process -Id (Get-NetTCPConnection -LocalPort 5173).OwningProcess | Stop-Process -Force

Q3: H2 Console says "Connection refused"
A3: Change JDBC URL from "jdbc:h2:tcp://localhost/~/test" to:
    jdbc:h2:mem:examind_dev
