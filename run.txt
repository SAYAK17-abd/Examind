1. PREREQUISITES & ENVIRONMENT
================================================================================
- OS: Windows 10/11
- Java: JDK 21+ installed (e.g. Oracle OpenJDK 21 or 25)
- Python: Python 3.11+ installed with uvicorn
- Node.js & Package Manager: Node v18+ with pnpm or npm
- Maven: Not required separately! The Maven Wrapper (mvnw.cmd) is bundled.

Project Root Directory:
d:\CODES\project.all\own\AI_projects\EXAMIND

================================================================================
2. METHOD 1: 1-CLICK LAUNCHER (RECOMMENDED)
================================================================================
We have created automated launchers that start all 3 services in separate windows:

OPTION A — Using Windows File Explorer:
Double-click:
    run_all.bat

OPTION B — Using PowerShell:
In the project root, run:
    .\run_all.ps1

This will automatically open 3 separate terminal windows:
  [Window 1] Python FastAPI AI Service   -> http://localhost:8000
  [Window 2] Spring Boot Java Backend    -> http://localhost:8080
  [Window 3] React TypeScript Frontend   -> http://localhost:5173

================================================================================
3. METHOD 2: STEP-BY-STEP MANUAL LAUNCH (3 TERMINALS)
================================================================================
If you prefer running services manually in your own terminal tabs:

--------------------------------------------------------------------------------
STEP 1: Start the Python FastAPI AI Service (Terminal 1)
--------------------------------------------------------------------------------
Open Terminal 1 in the project root:

    cd ai-service
    python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

Wait until you see:
    "Application startup complete. Uvicorn running on http://0.0.0.0:8000"

--------------------------------------------------------------------------------
STEP 2: Start the Java Spring Boot Backend (Terminal 2)
--------------------------------------------------------------------------------
Open Terminal 2 in the project root:

    .\mvnw.cmd spring-boot:run

Wait until you see:
    "Started ExamindBackendApplication in X.XXX seconds"
Backend is now live on http://localhost:8080!

--------------------------------------------------------------------------------
STEP 3: Start the React + TypeScript Frontend (Terminal 3)
--------------------------------------------------------------------------------
Open Terminal 3 in the project root:

    cd frontend
    .\pnpm.cmd dev

(Or: npm run dev)

Wait until you see:
    "VITE v6.4.3  ready in XXX ms"
    "➜  Local:   http://localhost:5173/"

Open your browser at:
    http://localhost:5173

================================================================================
4. METHOD 3: DOCKER COMPOSE LAUNCH
================================================================================
If you have Docker Desktop installed and want to run via containers:

In the project root:
    docker-compose up --build -d

To check running containers:
    docker-compose ps

To stop all containers:
    docker-compose down

8. COMMON TROUBLESHOOTING & PORT CLEANUP
================================================================================

Q1: "Port 8080 (or 8000, 5173) is already in use"
A1: A previous process was left running. Run these PowerShell commands to kill:
    # Kill port 8080 (Backend)
    Get-Process -Id (Get-NetTCPConnection -LocalPort 8080 -ErrorAction SilentlyContinue).OwningProcess -ErrorAction SilentlyContinue | Stop-Process -Force

    # Kill port 8000 (AI Service)
    Get-Process -Id (Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue).OwningProcess -ErrorAction SilentlyContinue | Stop-Process -Force

    # Kill port 5173 (Frontend)
    Get-Process -Id (Get-NetTCPConnection -LocalPort 5173 -ErrorAction SilentlyContinue).OwningProcess -ErrorAction SilentlyContinue | Stop-Process -Force

Q2: H2 Console says "Connection refused"
A2: Ensure JDBC URL is set to "jdbc:h2:mem:examind_dev", not tcp://localhost.

Q3: How do I stop any service running in a terminal?
A3: Click inside the terminal window and press:
    Ctrl + C
